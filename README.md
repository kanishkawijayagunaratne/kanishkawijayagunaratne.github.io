Static HTML/CSS, no build step. Hosted on GitHub Pages.

## Local preview

Open `index.html` in a browser, or run a simple server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Custom domain

To use **www.kanishkawijayagunaratne.com**, add a `CNAME` file containing:

```
www.kanishkawijayagunaratne.com
```

Then point your domain’s DNS to GitHub Pages (see [GitHub’s docs](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site)).
