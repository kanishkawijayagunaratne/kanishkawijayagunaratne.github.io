# Site images

Add these image files to this folder (same names as below). You can save them from your existing Google Site by right‑clicking each image → **Save image as** and naming them:

| Filename | Used for |
|----------|----------|
| `fellowship-vfa.jpg` | Venture for America card |
| `fellowship-venture-cooperative.jpg` | Venture Cooperative card |
| `fellowship-iventure.jpg` | iVenture Accelerator card |

JPG or PNG are fine; if you use PNG, update the `.jpg` extension in `index.html` to `.png` for that image.
